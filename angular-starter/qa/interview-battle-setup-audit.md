# Interview Battle Setup Audit

## Overall verdict

The original screen was visually clean but product-heavy: seven configuration groups competed for attention before the user could practise. The revised flow makes role, experience, and focus the only visible decisions; interview mechanics remain available without blocking the main task.

## Steps

1. **Choose interview target — healthy.** Role and experience appear together with senior-friendly defaults and a short explanation.
2. **Choose focus — healthy.** Eight common topics are visible, selected state is unambiguous, selection is capped at three, and less common topics are disclosed on demand.
3. **Customize interview — healthy.** Difficulty, style, duration, type, and assistance are collapsed by default and summarized in one line.
4. **Start practice — healthy.** The action sits beside a plain-language preview of the session that will begin.

## Accessibility notes

- Native select and details/summary controls retain keyboard behavior.
- Labels remain associated by containment and selected topics have both color and icon changes.
- The full keyboard focus order and screen-reader announcements still need manual assistive-technology testing.
